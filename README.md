# KeybindGlow

**English** · [Español](#español)

WoW addon that highlights the abilities bound to the modifier you are holding (Shift, Ctrl, Alt) with a customizable colored border. The interface is shown in English or Spanish depending on your game client language.

### Installation

Copy the `KeybindGlow` folder into `World of Warcraft/_retail_/Interface/AddOns/`.

### Usage

- `/kg` — open the options panel
- `/kg color <name|#RRGGBB>` — change the border color
- `/kg size N` — border thickness, 1 to 8 px
- `/kg combat` — only show in combat
- `/kg reset` — restore defaults

## Español

Addon de WoW que resalta con un borde de color personalizable las habilidades bindeadas al modificador que mantienes pulsado (Shift, Ctrl, Alt). La interfaz aparece en español o en inglés según el idioma del cliente.

### Instalación

Copia la carpeta `KeybindGlow` en `World of Warcraft/_retail_/Interface/AddOns/`.

### Uso

- `/kg` — abre el panel de opciones
- `/kg color <nombre|#RRGGBB>` — cambia el color del borde (`rosa`, `azul`, `verde`...)
- `/kg grosor N` — grosor del borde, de 1 a 8 px
- `/kg combate` — mostrar solo en combate
- `/kg reset` — restablecer valores por defecto
