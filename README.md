# BordeModificador

Addon de WoW que resalta con un borde de color las habilidades bindeadas al modificador que mantienes pulsado (Shift, Ctrl, Alt).

## Instalación

Copia la carpeta `BordeModificador` en `World of Warcraft/_retail_/Interface/AddOns/`.

## Uso

- `/bmod` — abre el panel de opciones
- `/bmod color <nombre|#RRGGBB>` — cambia el color del borde
- `/bmod grosor N` — grosor de 1 a 8 px
- `/bmod combate` — activar solo en combate
- `/bmod reset` — restablecer valores por defecto
